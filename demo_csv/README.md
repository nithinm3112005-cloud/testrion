# Demo CSV files for Testrion

Upload any of these in the app: **Datasets -> Upload CSV** (or New Test -> upload box), pick the target column, run the tests, then try **Auto-fix**.
All data is synthetic (generated by `make_demo_csv.py`, seeded, reproducible). Regenerate with
`backend/.venv/bin/python demo_csv/make_demo_csv.py`.

| File | Rows | Task | Target column | What it is built to show | Measured result (suggested model -> after Auto-fix) |
|---|---|---|---|---|---|
| `used_car_prices.csv` | 1,535 | Regression | `price_lakhs` | Missing values, duplicates, outliers, skewed price | Linear Regression: score 82, APPROVED -> Gradient Boosting: score 100, R² 0.92 |
| `energy_consumption.csv` | 1,200 | Regression | `energy_kwh` | Clean regression data; only robustness issues | Linear Regression: score 91, R² 0.96 -> score 98 |
| `loan_approval.csv` | 2,200 | Binary classification | `approved` | **Fairness**: gender, age and region columns; deliberate bias; missing income | Logistic Regression: score 65, **BLOCKED** (fairness) -> score 98, **APPROVED**, accuracy 89% |
| `fraud_transactions.csv` | 3,060 | Binary classification | `is_fraud` | **Target leakage** (`chargeback_flag`), severe imbalance (about 7% fraud), duplicates, missing values, a constant column | Logistic Regression: BLOCKED (leakage) -> Gradient Boosting: score 88, APPROVED |
| `student_grades.csv` | 900 | 3-class classification | `grade_band` | A hard, noisy problem the gate should **not** approve | KNN: score 63 -> Logistic Regression: score 86 but still **BLOCKED** (accuracy 79.6% < 85%) |
| `quick_small_test.csv` | 120 | Binary classification | `label` | Tiny file for a 5-second smoke test | Decision Tree: score 73, BLOCKED (overfitting) -> Logistic Regression: score 80, APPROVED |

Notes
- `student_grades.csv` stays blocked on purpose: no model reaches 85% accuracy on it, which shows the gate doing its job.
- Column names containing gender, age, region (and similar) are audited for fairness automatically. Names like `account_age_days` are not
  treated as personal attributes. You can mark any other column as protected under **Advanced options**.
- Scores come from one run on one machine; small differences are normal.
